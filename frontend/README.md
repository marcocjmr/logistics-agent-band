# Frontend Dashboard - Next.js

This directory contains the user interface for the Corporate Logistics & Relocation Orchestrator, showcasing real-time collaboration between AI agents.

## Design Concept

The dashboard uses a dual-panel layout to clearly separate agent communication from the final user outcomes:

1. **Left Panel: Orchestration Console**
   - Displays real-time logs of the conversations, JSON payloads, and state updates happening between the 4 agents inside the Band.ai WebSocket room.
   - Designed to feel like a modern, terminal-inspired system log.

2. **Right Panel: Visual Output & Results**
   - Renders interactive flight timelines, hotel details, and auditor approval states as the agents reach a consensus.
   - Designed with a premium, sleek enterprise aesthetic using dark mode and clean typography.
